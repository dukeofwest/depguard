Know the health of any GitHub repository.

Analyse dependencies, security practices, maintenance activity and engineering signals in one clear report.

Analysis runs entirely in your browser against the GitHub and OSV.dev public APIs. No account, no token, and nothing you enter is stored or sent anywhere else.

DepGuard reports observable repository signals. Its score is a heuristic assessment, not a security certification, and a repository with no detected vulnerabilities is not guaranteed to be safe.
