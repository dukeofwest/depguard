What DepGuard cannot tell you

  • It does not read or execute source code, so it cannot find vulnerabilities in the code itself.
  • It can see that a configuration file exists, but not whether Dependabot alerts, code scanning or CI runs are actually enabled and passing — that needs authentication.
  • Vulnerabilities can only be checked for dependencies with an exact version. Projects that do not commit a lockfile declare version ranges, which cannot be matched against advisory databases.
  • No detected vulnerabilities is not the same as safe. Every report shows how much of the intended analysis it was actually able to complete.
